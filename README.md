# Nex Chat Hider

Nex announces every special attack in the chatbox, burying everything else during the fight. This plugin tidies that up.

## Settings

**Nex messages**
- **Only show latest** (default): each new Nex line replaces her previous one, so only her most recent shout stays in the chatbox.
- **Hide all**: none of Nex's lines appear in the chatbox.

Only the chatbox is affected; her overhead text is unchanged. Changing the setting or toggling the plugin updates messages already in the chat, and disabling it brings all of her lines back.
